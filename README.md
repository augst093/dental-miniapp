# 🦷 DentaLux Tashkent — B2B Dental Clinic Platform (Mini App & Admin Suite)

Готовая к коммерческой продаже B2B-система автоматизации стоматологической клиники в Ташкенте ($450 внедрение + $50/мес сопровождение). Включает клиентскую витрину для Telegram Mini App, встроенную панель администратора, аналитический отчёт для владельца клиники и движок предотвращения накладок.

Развернуто: [https://dentalminiapp.vercel.app](https://dentalminiapp.vercel.app)  
Стек: **Next.js 16 (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS v4**, **Prisma v6**, **Telegram WebApp SDK**.

---

## 🌟 Ключевые возможности

### 1. Клиентская витрина (Patient View)
- **Каталог услуг и 3D-расчёт:** Брекеты (Damon), элайнеры (Spark), импланты (Straumann/Osstem), виниры (E.max), терапия.
- **Интерактивный калькулятор:** Прозрачная смета с детализацией материалов, анестезии и плана лечения без страха предоплаты.
- **Карточки врачей:** Опыт 9–16 лет, международные сертификаты ITI / Ormco, прозрачная квалификация.
- **Бронирование слотов без дублей:** 30-минутный шаг, минимальный lead time 2 часа, защита от двойной записи на уровне транзакций/state machine.
- **Мультиязычность:** Мгновенное переключение RU / UZ / EN.
- **Согласие на обработку персональных данных:** Чекбокс с сохранением отметки времени `consent_at` согласно законодательству Республики Узбекистан.

### 2. Панель администратора (Admin Panel)
- **Прямо внутри Telegram Mini App:** Не требует скачивания отдельных приложений. Доступ проверяется через криптографическую валидацию HMAC-SHA256 подписи Telegram `initData` по белому списку `ADMIN_ID`.
- **Лента «Сегодня»:** Все записи на день с бейджами статусов (`Ожидает`, `Подтвержден`, `Завершён`, `Не явился`, `Отменён`).
- **Быстрые действия в 1 тап:**
  - ✅ Подтвердить визит
  - 🦷 Пациент пришёл
  - ❌ Не явился (No-show)
  - 🚫 Отменить запись
  - 📞 Быстрый звонок пациенту (`tel:+998...`)
  - 💬 Написать в Telegram в 1 клик
- **Календарь на 7 дней:** Просмотр загрузки клиники по дням недели.
- **Быстрая ручная запись:** Администратор может внести пациента, записавшегося по телефону.
- **Быстрое управление графиком врачей:** Включение/отключение рабочих смен докторов на текущую неделю.

### 3. Отчёт для владельца клиники (Owner Report)
- **Аналитика за 7 и 30 дней:**
  - Процент подтверждения записей (Confirmation Rate)
  - Доля неявок (No-show Rate)
  - Спасенные слоты благодаря автоматическим напоминаниям
  - Экономия рабочего времени администратора (из расчета 4 мин на звонок)
- **Легковесный SVG-график:** Наглядная динамика записей без тяжелых сторонних библиотек.
- **Кнопка «Отправить дайджест в Telegram сейчас»:** Мгновенный срез ключевых показателей для директора.

### 4. Режим демонстрации (Demo Mode)
- Управляется флагом `DEMO_MODE=true` в `.env`.
- Включает дискретную плавающую шторку **Demo Control Drawer**:
  - Быстрое переключение ролей: Пациент / Администратор
  - Триггер «Отправить напоминание сейчас»
  - Генерация тестовой записи на завтра
  - Симуляция отмены визита и освобождения слота
  - Сброс демо-данных к реалистичному 14-дневному состоянию

### 5. Конфигурация в один файл (`clinic.config.ts`)
Все параметры клиники вынесены в `src/clinic.config.ts`:
- Название и слоган
- Телефон регистратуры и Telegram-юзернейм
- Адрес, ориентир и координаты Яндекс.Карт
- Номер медицинской лицензии (опционально, скрыт по умолчанию)
- Рабочие часы и слот-сетка
- Список врачей и каталог услуг

## 🛠 Быстрый старт и запуск

### 1. Установка зависимостей:
```bash
cd dental_miniapp
npm install
```

### 2. Настройка окружения:
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env.local
```
Заполните `BOT_TOKEN`, `ADMIN_ID` и при необходимости `DATABASE_URL`.

### 3. Запуск тестов:
Автоматизированный тестовый набор проверяет переходы стейт-машины, предотвращение овербукинга, расчет напоминаний и HMAC-валидацию:
```bash
npm test
```
*Результат: 17/17 тестов пройдены успешно.*

### 4. Запуск локального сервера разработки:
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:3000`.

### 5. Сборка для продакшена:
```bash
npm run build
npm run start
```
