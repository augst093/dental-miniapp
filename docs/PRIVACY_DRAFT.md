# Политика обработки персональных данных (ЧЕРНОВИК)

> Черновик для проверки юристом клиники. Это не юридическая консультация и не готовый документ.
> Перед использованием проверьте текст на соответствие законодательству Республики Узбекистан о персональных данных.

## 1. Какие данные собираем
- **Имя**, которое пациент указывает при записи или которое передаёт Telegram.
- **Номер телефона** в формате +998 для связи по записи.
- **Telegram ID** пациента, если запись сделана через бота или приложение в Telegram.
- **Услуга, врач, дата и время визита**, статус записи.
- **Вопросы, отправленные администратору** через чат (инбокс), и ответы на них.

## 2. Зачем
- Записать пациента на приём и подтвердить запись.
- Напомнить о визите за 24 часа и за 2 часа.
- Ответить на вопрос пациента через администратора.
- Вести статистику записей клиники без указания личности (отчёты владельцу).

Данные не передаются третьим лицам, кроме поставщиков инфраструктуры (хостинг, база данных, Telegram), которые нужны для работы сервиса.

## 3. Согласие
- При записи пациент ставит отметку о согласии на обработку персональных данных.
- Сохраняется время согласия.
- Текст согласия: [вставить итоговый текст, проверенный юристом].

## 4. Срок хранения
- Записи и контакты хранятся **[N]** месяцев после последнего визита, затем обезличиваются. Значение задаёт клиника.

## 5. Права пациента
- Запросить копию своих данных.
- Исправить данные.
- Удалить данные: команда `/delete_my_data` в боте или запрос администратору клиники. Имя и телефон заменяются на обезличенные значения, статистика сохраняется.
- Отозвать согласие: тем же способом. Это приводит к удалению данных, кроме сведений, которые клиника обязана хранить по закону.

## 6. Безопасность
- Доступ к данным у сотрудников только по роли (администратор, владелец).
- Персональные данные не передаются в ИИ-ассистент: номера телефонов маскируются до отправки.
- Данные хранятся в базе данных PostgreSQL, передача по защищённому соединению (HTTPS).

## 7. Контакты
