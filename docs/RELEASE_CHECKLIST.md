# Выкатка: ветка feature/mandatory-spec

Ничего не слито в `main` и не выкачено. Слияние и выкатку делает владелец.

## Что входит

**Mini App** (`dental_miniapp`, ветка `feature/mandatory-spec`):
- Защита API: демо-эндпоинты отвечают 404 без `DEMO_MODE=true`.
- Врачи и услуги в базе, API и экраны в админке, снимок цены в записи.
- Инбокс: вопросы из чата, ответы через очередь, вкладка в админке.
- Очередь исходящих сообщений (`Outbox`), повтор неотправленных.
- Кнопка «О враче», переходы и мелкие правки интерфейса.

**Бот** (`dental_ai_bot`, ветка `feature/mandatory-spec`):
- Отправитель очереди: повторы, лимиты Telegram, миграция группы в супергруппу.
- Напоминания и все проактивные сообщения идут через очередь.
- Кнопка «Приду» идемпотентна.

## Порядок выкатки

1. **Схема базы** (боевой `DATABASE_URL`, из папки `dental_miniapp`):
   ```
   npx prisma db push
   ```
   Изменения только добавляют: таблицы `InboxThread`, `InboxMessage`, `Outbox`, перечисления `InboxStatus`, `OutboxStatus`, колонки `Appointment.priceUzs` (пусто для старых записей), `Service.sortOrder` (по умолчанию 0), `Outbox.replyMarkup`. Существующие данные не меняются. Перед запуском сделайте резервную копию (см. задачу по бэкапам).
2. **Mini App на Vercel**: слить ветку в `main`, выкатить. Переменные: `BOT_TOKEN`, `ADMIN_ID`, `ADMIN_CHAT_ID` (уже заданы; `ADMIN_CHAT_ID` должен быть текущим ID боевой группы).
3. **Бот на Railway**: слить ветку в `main`, дождаться сборки. Переменные: `DATABASE_URL` (уже задан), `ADMIN_CHAT_ID` (текущий ID группы).

Бот нужно выкатывать **после** схемы: он читает таблицу `Outbox`.

## Проверка после выкатки

- Логи бота: строки «Outbox worker запущен» и «Бот DentaLux … успешно запущен».
- `GET /api/health` отвечает 200.
- Запись через Mini App: в группе появилось сообщение о новой записи.
- Ответ из инбокса: в переписке статус «доставлено» через несколько секунд.
- Напоминание: придёт в личку с тремя кнопками. Нажатие «Приду» меняет статус.
- В базе: строки `Outbox` со статусом `sent`, без застрявших `pending`.

## Откат

- Mini App: вернуть предыдущий деплой в Vercel (Deployments → Promote).
- Бот: вернуть предыдущий коммит `main` на Railway.
- Схема: изменения аддитивные, откат не требуется. Новые таблицы можно оставить пустыми.

## Что ещё не сделано

- Экран неотправленных сообщений в админке (API уже есть: `/api/admin/outbox`).
- Приложение пациента читает врачей и услуги из кода, а не из базы.
- Расписание по исключениям (отпуск, выходной на дату, перерыв).
- Тексты врачей и услуг только на русском.
- Бэкапы и тест восстановления.
- Сквозной тест на боевом боте с реальными пациентами не проводился.
